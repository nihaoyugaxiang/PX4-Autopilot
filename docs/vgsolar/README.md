## 本轮用户决定

用户要求基于现有板级版本逐步迁移光伏机器人功能，校准及磁航向问题暂缓。
因此先推进不依赖磁航向的输入驱动和通信；原任务书中“传感器验收后才进入后续阶段”在这些独立工作上按用户决定调整。
磁航向仍标记待验收，自动按航向转弯和导航不由本轮工作放行。现有IMU/罗盘代码、安装旋转、校准和MBE设置保持原状。
