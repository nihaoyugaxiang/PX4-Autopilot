# 第19篇：APM → PX4 软件差异补齐说明

日期：2026-11-01。对应此前复核 F01—F10。此版补齐已确认的软件缺口；平台差异和实机验收边界明确保留，不宣称 APM/PX4 全部动态行为相同。

## 本版变化及复核对应

| 编号 | 修改 | 证据与剩余边界 |
|---|---|---|
| F01 | 急停进入放气、缓变抬升、IR补行程；重复请求不重置时间；仅升降可在已解锁急停时继续，履带／刷／泵关停 | 生产模式测试急停时仍处于放气、PWM保持原位，随后才抬升；上锁、kill、退出模式不越过 PX4 输出许可，保留 release_pending 待释放，不将请求当作已抬起 |
| F02 | 增加 VGS_SC_VAC_HYST，保持掉压只告警；阈值回差、连续消抖、恢复清告警 | 单测覆盖死区、告警保持、恢复和不放气；建压超时仍故障 |
| F03 | 冻结时继续观察压力，记录冻结前可保压状态，抬升过程中冻结按已吸附恢复 | 单测覆盖冻结掉压仍密封、泵停止；告警状态进模式状态和事件日志 |
| F04 | VGSolar板型的 NAMED_VALUE_FLOAT 增加 SUCT_PKPA/SUCT_HLT，SCALED_PRESSURE2 兼容原表压×10 hPa；超时／停模块发送无效 NaN | 实际 MAVLink 源码板型编译通过；真实 QGC 消息到达未验收。原 DEBUG_VECT/VGS_PRESS 保留。仅板型宏启用，其他板不变 |
| F05 | 新增 vgsolar_link_status、vgsolar_event 日志：合法RX时间、累计计数及事件／周期队列丢弃，命令接受／拒因、模式阶段变化、看门狗、掉压告警／恢复、转弯完成／中止 | VGS_CC_LOG=0关闭、1速度变化或5Hz记录、2逐条记录；累计计数可由时间差得到秒窗。拒因按PX4语义分类，不保证旧DataFlash编号逐一相同；旧脚本需按新ULog消息适配 |
| F06 | 共用 VgsolarBattery.hpp：项目电压端点、限幅、四舍五入百分比、连接／电压有效性；NCU与20%关刷共用结果 | 默认 VGS_BAT_SRC=1，19.8..25.2 V；0可用原生估算。单测覆盖中间值、上下限、无效与断开。原生 battery_status 和标准地面站电量仍保留PX4估算，可能与NCU不同；这是明确的接口边界 |
| F07 | 导航新增指令起点至目标的直线前视跟踪，偏航大时减速，按剩余制动距离减速，保留倒车符号 | 简化平面运动测试覆盖2m横向偏差回归目标；这不是完整SITL/HIL或APM wp_nav算法等价证明；多场景轨迹与实车精度仍待验收 |
| F08 | 导航拒绝处理接收本条请求坐标类型，失败反馈不再沿用旧类型 | 生产模式回归明确断言GPS被拒后nav_mode=1 |
| F09 | VGS_TURN_TO只计算TURNING旋转阶段；建压默认10000ms、-70kPa、300ms，与APM本板基线对应 | 升降与建压仍有各自超时；不再让建压耗尽15s旋转时间。仍保留净转角和航向重置中止等改进 |
| F10 | VGS_ESC_OFS发布偏移；逐设备success/CRC/timeout/bad-response/exception；响应超时40ms，轮询周期从请求开始计 | 标准esc_status索引带偏移，原始数组仍为配置槽位；不再以“在线”伪造armed；CRC／异常计数已加入协议回归，实际总线频率待测 |

## 新参数与默认变化

| 参数 | 当前默认 | 用途 |
|---|---|---|
| VGS_SC_VAC_HYST | 5 kPa | 掉压门槛=建压阈值+回差；恢复需回到建压阈值 |
| VGS_SC_VAC_KPA / VGS_SC_VAC_DLY / VGS_SC_VAC_DEB | -70 kPa / 10000ms / 300ms | 对齐APM板级吸附基线；旧持久参数不会自动覆盖 |
| VGS_NAV_DEC | 0.5 m/s² | 目标附近制动速度上限 |
| VGS_BAT_SRC | 1 | 1项目电压换算，0原生剩余电量；作用于NCU和刷子保护 |
| VGS_BAT_MIN / VGS_BAT_MAX | 19.8 / 25.2 V | 整包电压0%/100%端点 |
| VGS_CC_LOG | 1 | 通信诊断与事件日志档位 |
| VGS_ESC_OFS | 0 | 标准ESC发布索引起始偏移；offset+count≤8 |

VGS_ENABLE、VGS_CLN_EN、VGS_ESC_EN、VGS_WHL_CTRL、VGS_WHL_RAD仍默认0；没有替用户启用执行器。保留原输出候选映射和原生上锁限制。电压／电流采样倍率20.65和85是参考配置，实际标定尚待验证，未把未测电流零偏直接写入。

## 释放与状态的准确含义

已解锁、处于VGSolar且清洁许可有效时，软件急停保持升降输出推进释放，并强制刷子、泵和履带停止。上锁、kill、退出模式或撤销清洁许可时，所有执行输出仍按PX4撤销，软件保留待释放动作；重新进入并获得许可后必须先完成释放，再允许行驶。`cleaner_output_permitted`、`release_pending`、`suction_state`和`vacuum_warning`用于观察这些区别。没有实现跨模式的独立机构执行器，也不绕过上锁强行输出。IR／机构故障时不能保证释放完成，需要实机验收和物理处理。
