# 可选输出参数配置

在QGC参数页面导出原参数后加载所需`.params`文件，再回读确认；文件为QGC参数文本格式（系统ID、组件ID、名称、值、类型）。没有逐机校准值或身份信息。

`rover_apm_wiring.params`只适用于VGSolar原APM机器人接线，且已应用差速车机架50000。MAIN1/PE13=Motor2左，MAIN2/PE14=Motor1右，MAIN3/PD14=外设1升降，MAIN4/PD15=外设2后滚刷，MAIN5/PC8=外设3前滚刷。文件设置三组50 Hz，不修改上锁/失效值；本板默认和已测试台架配置为0，加载后须回读确认。QGC通用DIS参数元数据下限为800，但本板启动默认的0表示无有效高电平脉冲，不应仅为满足界面范围而改成设备未经标定的脉宽。后三路是接口预留，当前固件未实现原APM自动清洁控制。0脉冲是否使设备停止必须实测；本文件不设置电调方向、范围和中位。

`outputs_disabled.params`将五路功能恢复为Disabled。切换Copter后按实际机架重新配置输出，不沿用机器人参数。当前固件默认输出未分配，不自动加载这些可选文件。
